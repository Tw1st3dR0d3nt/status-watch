# Security Policy

## Reporting a Vulnerability

If you believe you have discovered a security vulnerability affecting StatusWatch, please report it privately.

Please do not publicly disclose the vulnerability before it has been reviewed.

When reporting a security issue, please include:

- A description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any relevant screenshots, logs, or other supporting information

Security reports will be reviewed and addressed as appropriate.

## Scope

This policy applies to the StatusWatch Discord application and its associated services.

The StatusWatch source code is proprietary and is not publicly available.
